# SaveMoney 💰

O SaveMoney é um site para ajudar no controle das finanças pessoais.

A ideia do projeto é deixar mais fácil organizar receitas, despesas e acompanhar como o dinheiro está sendo usado no dia a dia.

## 🌐 Acesse o site

[**SaveMoney**](https://projeto-a3-save-money.onrender.com)

## O que dá para fazer

- Criar uma conta e fazer login
- Adicionar receitas e despesas
- Organizar movimentações por categorias
- Ver o histórico financeiro
- Acompanhar gráficos
- Criar metas financeiras
- Fazer um planejamento mensal
- Editar o perfil
- Alternar entre modo claro e escuro
